# Practical 9: std::move() in C++ (Utility Library)

## Description
Implementation of `std::move()` in C++ using the `<utility>` library to transfer a shopping bag's item from one object to another.

## Concepts Covered
- Class and objects
- Constructor
- Multiple data types (`string`, `int`, and `double`)
- `std::move()` and move semantics
- Utility library

## Objective
To understand how `std::move()` helps transfer resources between objects efficiently.

## Real-Life Example
A shopping bag contains an item, its quantity, and its price. The item is moved from one shopping bag object to another, while the quantity and price are copied.

## Conclusion
Through this practical, I learned how to use `std::move()` with classes, constructors, and different data types in C++.
